# Analysis/ — Results notebooks

Reads the `Outputs/*.tar.gz` archives and the ground-truth pickles in `Data/`, and produces the
metrics, ablations, and figures.

| Notebook | Scope |
|----------|-------|
| `llm_results.ipynb` | **Final results.** Test set (879 cases): coverage, per-config metrics (F1/MCC/acc), baseline-vs-tool confusion deltas, fine-tuning deltas, per-case error analysis. Also loads the TRAIN archives for the train↔test comparison. |
| `llm_train_results.ipynb` | Train-set diagnostics: tool-vs-oracle deltas, ADM-config / question-set / history / temperature / max-tokens / trim ablations, factor-level early-termination error analysis. |
| `ADM_viz.ipynb` | Renders the ADM and every ablation variant as graphs. |

## Data sources

- Ground truth: `Data/train_data_Inv_Step.pkl`, `Data/test_data_Inv_Step.pkl`
  (`Reversed→Yes`, `Affirmed→No`).
- Predictions: the `Outputs/*.tar.gz` catalogue defined in the `ARCHIVES` / `TEST_ARCHIVES`
  lists near the top of `llm_results.ipynb`. Each entry is `type='tar'`, a `path`, and the
  internal `prefix` used to filter tar members. **Add an entry here whenever you add an archive
  to `Outputs/`.**

## Figures

Figures generated by code route to the repo-level [`../Figs/`](../Figs/) directory (`FIGS_DIR`).
The ADM-graph SVGs from the factor-error analysis are written under `Figs/` as well; the older
`adm_viz/` subfolder here is legacy.

> Note: vLLM is non-deterministic even at `temp=0`; headline configs use 3 runs and the
> notebooks report per-run variance / bootstrap CIs. Treat single-run numbers as indicative.
