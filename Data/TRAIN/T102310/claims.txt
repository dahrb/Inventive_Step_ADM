WHAT IS CLAIMED IS:

1. A method for establishing a communication link
between a mobile platform and a remote computer system, said method

comprising:

storing fault data in a mobile platform onboard computer

system database;

placing a transmittable data file containing the fault data into
an outgoing queue of a second portion of a communications management
function (62B), hereafter referred to as CMF2, of the mobile platform
onboard computer system (14), hereafter referred to as OCS;

automatically selecting at least one desired communication
channel type between the OCS (14) and a remote central computer
system (20), hereafter referred to as CCS, from a plurality of available
communication channel types included in a configuration file of the CMF2
(62B); and

sending the transmittable data file from the CMF2 (62B) to
the a first portion of a communications management function (62A),
hereafter referred to as CMF1, of the CCS (20), via a secure established

link over the automatically selected channel.

storing the fault data in a remote central computer system
database so that the fault data in the mobile platform onboard computer
system database and the fault data in the remote central computer system

database are synchronized.

2. The method of Claim 1 wherein placing the
transmittable data file into the outgoing queue comprises:

sending a message containing data to be downloaded
