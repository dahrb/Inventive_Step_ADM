1. An information processing method comprising the steps
of:

receiving (S3) a command from an provider apparatus
(1) providing a service by provider;

processing (S84) the command by utilizing a memory
section (66) including a first area and a second area,
wherein the first area including a plurality of provider
area definition blocks each of which stores information
relating to a provider area (BN y..BN,) of a plurality of
provider areas (BNo..BNi) in the second area and access
right data which define access rights to said provider
area (BNo..BN;) so that the provider area (BNO..BN1)
associated with one provider of a plurality of providers
can be accessed by said one provider; and

transmitting (S5) results of the processing to the
provider apparatus (1),
characterized in that

the memory section (66) is formed from a plurality of
physical blocks each of which has a predetermined size;

the first area size being based on the number of the
providers, wherein the number of the providers corresponds
to the number of the provider area definition blocks and
each of the provider area definition blocks has said
predetermined size; and

the second area size being equal to the difference
between the size of the memory section and the first area
size, wherein the second area is formed from a plurality
of user blocks each of which has said predetermined size
and each of said provider areas (BNo..BN;) is formed from

a plurality of said user blocks.
