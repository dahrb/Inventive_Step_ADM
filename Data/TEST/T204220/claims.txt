CLAIMS (MAIN REQUEST)

1. A storage system, wherein the storage system comprises a controller (100) and a solid
state disk (200), the controller (100) is capable of communicating with the solid state disk (200),
the solid state disk (200) comprises multiple channels, and each of the multiple channels is
connected to multiple dies, wherein

the controller (100) is configured to: create multiple segments; select a first die from the
multiple dies; select a first segment from the multiple segments, and determine an available
offset of the first segment; generate a write request, wherein the write request comprises a write
address, target data, and a data length of the target data, and the write address comprises an
identifier of a channel connected to the first die, an identifier of the first die, an identifier of the
first segment, and the available offset; and send the write request to the solid state disk (200);

the solid state disk (200) is configured to receive the write request, and store the target data
according to the write address and the data length of the target data; and

wherein the controller (100) is further configured to record an amount of valid data stored in
each of the multiple dies; and the controller (100) is specifically configured to select a die in
which an amount of valid data is less than a second threshold as the first die;

wherein selecting the first die based on the second threshold comprises applying a criterion
selected from

- Criterion 1: Random principle,

- Criterion 2: Stateless priority principle,

- Criterion 3: Performance priority principle,

- Criterion 6: Read request latency principle.

configured to record states of the multiple dies; and
