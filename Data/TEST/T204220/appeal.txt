The appeal is against the examining division's decision to refuse the European patent application. II. The examining division decided that the application did not meet the requirements of Articles 84 or 56 EPC. III. The documents referred to by the examining division included: D1|US 2016/110107 A1| IV. In its statement of grounds of appeal, the appellant requested that a patent be granted on the basis of the claims in accordance with either the main request or the first or second auxiliary request, all of which were submitted with the statement of grounds of appeal. The claims of the main request were identical to the first auxiliary request underlying the decision under appeal. The appellant requested oral proceedings in the event that none of the requests was found to be allowable. V. The board issued a summons to oral proceedings. It also provided its preliminary opinion on the case (Article 15(1) RPBA 2020). The board concurred with the findings of the examining division that the claims of the main request did not meet the requirements of Article 84 EPC. As for the first auxiliary request, the board held that it did not fulfill the requirements of Article 84 EPC, but did comply with Article 56 EPC. The board indicated that it was inclined not to admit the second auxiliary request into the proceedings. VI. In a reply dated 20 December 2022, the appellant provided further arguments regarding the pending requests and submitted a third auxiliary request. VII. In a communication dated 23 December 2022, the board expressed its preliminary opinion that the third auxiliary request complied with the requirements of the EPC and explained why it considered the arguments provided with respect to the higher-ranking requests unconvincing. VIII. In its reply dated 12 January 2023, the appellant changed the order of the requests such that the third auxiliary request became the new main request and the other requests were also re-ranked and renamed. It requested that the decision under appeal be set aside and that a patent be granted based on the new main request or the new first auxiliary request, which was the former main request, or the new second auxiliary request, which was the former first auxiliary request, or the new third auxiliary request, which was the former second auxiliary request. IX. The board informed the appellant that the oral proceedings had been cancelled. X. Claim 1 of the main request reads as follows: "A storage system, wherein the storage system comprises a controller (100) and a solid state disk (200), the controller (100) is capable of communicating with the solid state disk (200), the solid state disk (200) comprises multiple channels, and each of the multiple channels is connected to multiple dies, wherein the controller (100) is configured to: create multiple segments; select a first die from the multiple dies; select a first segment from the multiple segments, and determine an available offset of the first segment; generate a write request, wherein the write request comprises a write address, target data, and a data length of the target data, and the write address comprises an identifier of a channel connected to the first die, an identifier of the first die, an identifier of the first segment, and the available offset; and send the write request to the solid state disk (200); the solid state disk (200) is configured to receive the write request, and store the target data according to the write address and the data length of the target data; and wherein the controller (100) is further configured to record an amount of valid data stored in each of the multiple dies; and the controller (100) is specifically configured to select a die in which an amount of valid data is less than a second threshold as the first die; wherein selecting the first die based on the second threshold comprises - valid data amount balancing principle, wherein if there are multiple dies in which the amounts of valid data are less than the second threshold, the controller (100) has a processing manner: selecting a die in which an amount of valid data is smallest as the first die." XI. Independent claims 6 and 10 are directed to a corresponding solid state disk and to a corresponding method, respectively. XII. The claims of the lower-ranking requests are of no relevance for this decision.
