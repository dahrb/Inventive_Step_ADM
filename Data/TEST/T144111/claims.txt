MAIN REQUEST
CLAIMS:

1. An application determining apparatus of an image forming apparatus (10),
characterized by:

a log recording unit (42) configured to record, in response to at least one
of a use request for use of a predetermined function of the image forming
apparatus from an application for use in the image forming apparatus and
consumption of a memory of the image forming apparatus by the application,
memory consumption of the application in each of a number of states of the
application as log information; and

a determining unit (334) configured to determine whether a maximum
value of memory consumption of the application in each state of the application is

less than or equal to a predetermined restriction.

2. An application determining apparatus as claimed in claim 1, further
characterised in that when two applications are activated in the image formation
apparatus and transitions of said states of the two applications are performed at
the same time, the determining unit (334) is arranged to determine whether a
sum of maximum memory consumption in each of the states of the two

application is less than or equal to the predetermined restriction.

3. An application determining apparatus as claimed in claim 1 or 2, further
characterized by:

a responding unit configured to respond, if the application is activated for
which application the determination by the determining unit (334) is to be made,
to the use request for use of the predetermined function from the application in
place of a function realizing unit configured to realize the predetermined function

according to the use request.
