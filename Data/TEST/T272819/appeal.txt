The appeal is against the decision of the examining division refusing European patent application No. 10 793 722 (published as WO 2011/001412 A1) on the grounds of lack of novelty and inventive step (Articles 52(1), 54(1) and 56 EPC). II. The appellant (applicant) requested at the oral proceedings before the board that the decision under appeal be set aside and a patent be granted on the basis of the first or the second auxiliary request, both filed with the appellant's letter dated 7 October 2019. The main request filed with the appellant's letter dated 7 October 2019 and the fourth auxiliary request specified in an "Addendum to statement of grounds for appeal" were withdrawn by the appellant during the oral proceedings before the board. No third auxiliary request was filed or specified. III. Reference is made to the following document cited in the decision under appeal: D4: US 2007/0174490 A1 IV. Claim 1 of the first auxiliary request is worded as follows: An advertising system for advertising in a mobile communication environment, the advertising system including:- an advertising server having advertising material stored thereon; mobile communication devices which are linked to the advertising server for communication therewith via a mobile communication network, each mobile communication device including a software application operable to save advertising material into a memory of the mobile communication device and upload advertising material from the memory to an interface means for presenting said advertising material to a user of the mobile communication device in response to an event detected by the software application, said event comprising an incoming call or incoming text message, or the device being used to make a call or send a text message, and a campaign server which polls said mobile communication devices for the purpose of establishing a connection between the campaign server and the mobile communications [sic] devices and which, upon a connection being established to a specific mobile communication device, activates the mobile communication device to a condition in which advertising material can be downloaded from the advertising server. V. Claim 1 of the second auxiliary request has the following wording (additional features with respect to claim 1 of the first auxiliary request underlined by the board): An advertising system for advertising in a mobile communication environment, the advertising system including:- an advertising server having advertising material stored thereon; mobile communication devices which are linked to the advertising server for communication therewith via a mobile communication network, each mobile communication device including a software application operable to save advertising material into a memory of the mobile communication device and upload advertising material from the memory to an interface means for presenting said advertising material to a user of the mobile communication device in response to an event detected by the software application, said event comprising an incoming call or incoming text message, or the device being used to make a call or send a text message, and a campaign server which polls said mobile communication devices for the purpose of establishing a connection between the campaign server and the mobile communications [sic] devices and which, upon a connection being established to a specific mobile communication device, activates the mobile communication device to a condition in which advertising material can be downloaded or pushed from the advertising server, wherein the campaign server continuously polls and attempts to connect to various devices at registered times. VI. The appellant argued essentially that the selection of "basic functions" of the mobile device, such as sending and receiving of text messages and calls in the context of displaying advertisements, had a technical effect and solved a technical problem. Such "basic functions" had priority in the operation of the mobile device and would trigger the displaying of the advertisements without the user having to take any action. The server actively polling the mobile devices and causing advertising content to be downloaded to them ensured that the content on the devices was up to date. Neither of those features were disclosed or suggested in D4; the claimed subject-matter was thus new and inventive.
