An advertising system for advertising in a mobile communication environment,

the advertising system including:-

an advertising server having advertising material stored thereon; mobile
communication devices which are linked to the advertising server for
communication therewith via a mobile communication network, each mobile
communication device including data receiving means for receiving said
advertising material, data storage means in which said advertising material can
be stored, and an interface means for presenting said advertising material to a
user of the mobile communication device in response to an incoming call or
incoming text message, or the device being used to make a call or send a text
message, and a campaign server which polls said mobile communication
devices for the purpose of locating and establishing a connection between the
campaign server and the mobile communications devices and which, upon a
connection being established to a specific mobile communication device,
activates the mobile communication device to a condition in which advertising

material can be downloaded from the advertising server.

Asystem as claimed in claim 1, wherein the campaign server continuously polls

and attempts to connect to various devices at registered times.

A system as claimed in claim 2, wherein the campaign server once connected

and a session established, commences with the data exchange.
