CLAIMS

A computer-implemented method for automatically positioning labels associated with a

visual data object, comprising:

determining a first layout for the labels;

scoring the first layout to determine a first score;
determining a second layout for the labels;

scoring the second layout to determine a second score;
comparing the first score with the second score;

proceeding with one of the first layout and the second layout as a selected layout for
rendering the visual data object depending on the comparison of the first score to the

second score; and

repeating determining an additional layout for the labels and scoring the additional layout
until a layout is achieved that approaches an optimal layout,

wherein labels that are manually positioned are exempt from consideration during the

optimization process.

The computer-implemented method of claim 1, wherein scoring the first layout to
determine a first score further comprises executing an objective function, wherein the
objective function provides a goal by which the first layout is scored.

The computer-implemented method of claim 2, wherein the goal corresponds to

minimizing overlap of the labels.

The computer-implemented method of claim 2, wherein the goal corresponds to
minimizing the distance from the labels to their associated anchors within the chart.
