Claims (Main request) 03. Sep. 2013

1. An apparatus for managing power in a computer system, the apparatus
comprising: .

an operation system (10) configured to set up a power mode of the computer
system, wherein the power mode includes at least one of an operating mode and a
power down mode;

at least one device (40) configured to perform specific functions and operations;

at least one device driver (20) configured to control operations of the device,
wherein the device driver (20) is configured to change a power mode of the device
among the at least one of the operating mode and the power down mode; and

a filter driver (100) coupled to the operation system (10), wherein the filter driver
(100) is configured to generate a signal to cause the device driver (20) to individually
change the power mode of the device to operate in the power down mode when the
computer system is in the operating mode,

characterized by a queue for storing IRP - input or output request packets -
generated by one or more control circuits,

wherein the filter driver (100) is configured: if the device is in the power down
mode when a packet enters into the queue, to transfer a power control message to the
device driver (20) to change the power mode of the device to the operating mode
before the first packet requested to be transferred by the operating system (10) is
transferred to the device driver (20); to transfer the requested packet to the device after

the power mode of the device is changed to the operation mode; and to set the power

6. A method for managing power in a computer system having a filter driver
(100) coupled to an operation system (10) and a device driver (20) for controlling a
device (40), said method comprising the following steps:

the filter driver’s transferring of a power control message to the device driver, if
the device is in the power down mode when a packet enters into a queue for storing
input or output request packets generated by one or more control circuits, to change
the power state of the device to an operating state before the first packet requested to
be transferred by the operating system is transferred to the device driver (20);

transferring the requested packet to the device after the power state of the device
is changed to the operating state; and

the filter driver’s setting of the power state of the device to the power down state

after the device completes handling the packet when the queue is empty.

7. The method according to claim 6, further comprising:

if a packet enters into a queue, automatically dispatching an associated device;

powering up the device if the device has been in the power down mode;

transferring one packet from the queue to an associated device driver; and

completing a routine if the queue is empty, and, transferring a power down IRP -
Input or Output Request Packets - to the device driver to change the power state of the

device to the power down mode.
