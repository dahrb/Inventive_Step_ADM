MAIN REQUEST

1. A method for connecting an augmented reality system based on computer
vision technology to a Knowledge Base System, KBS, storing mass data relating to a virtual
object, comprising:

providing for a defined action of user to provide an interaction between a user and a
virtual object displayed on an augmented reality screen of the augmented reality system;

providing a connection between the virtual object and the action of the user defined
for the interaction: and

providing a communication protocol for communicating between the augmented reality
system and the Knowledge Base System in both directions, the communication protocol including
a structure and the communication protocol defining a transfer of an event issued in the
augmented reality system by the defined action of the user for providing interaction to the KBS
and a transfer of a response to the event to the augmented reality system, wherein the augmented
reality system constitutes a client and the KBS constitutes a server in relation to the transfer of an

event and the transfer of a response using the communication protocol.

2. The method of claim |, wherein the defined action of the user is defined

according to a type of the virtual object or a condition.

3. The method of claim 2, wherein the action of the user comprises at least one of a

mouse click, a mouse over, a mouse double-click, a mouse scroll, gestures, and a voice control.

4. The method of claim 1, wherein as a structure for expressing the defined user
action for the interaction, a hotspot of the augmented reality screen comprises an ID, a name, a
position, a part number, an annotation element, and wherein the annotation element has a variety

of types each including ID, name, position, and color attributes.

5. An interaction system for connecting an augmented reality system based on
computer vision technology to a Knowledge Base System, KBS, storing mass data relating

to a virtual object, comprising:
