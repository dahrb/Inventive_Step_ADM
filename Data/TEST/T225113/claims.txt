CLAIMS

1. An interactive food and/or drink ordering system, in which a computer
controlled projector is mounted above a surface such that a menu of food and/or drink
selection options is projected onto some or all of the surface, the selection options being
selectable by a user operating an interface device which is built into the surface and

connected to the computer.

2. The system of Claim 1 in which the computer is connected to an EPOS
(electronic point of sale system) and provides information to kitchen and/or bar staff to

determine what food and/or beverages will be prepared.

3. The system of any preceding Claim in which the interface device is a track pad
interface.
4. The system of Claim 3 in which the track pad communicates with the computer

over a short range wireless network.

5. The system of any preceding Claim in which the interface device allows the user
to control a cursor projected onto the surface by the projector and to select items

projected onto the surface.

6. The system of any preceding Claim 1n which the surface is a surface of a table.

7. The system of Claim 6 in which the table is a conventional table, with no
embedded display.

8. The system of any preceding Claim in which the selection options includes

simple lists of food/beverage items with related icons and buttons that a user can select

using the interface device.

9. The system of any preceding Claim in which the computer and interface device
also allows the user to select different lighting for the table, for projection onto the

surface by the projector.
