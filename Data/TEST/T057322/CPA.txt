TITLE:
Smart trailer system

TYPE:
World International Patent Organisation

ABSTRACT:
A smart trailer system coupled to a trailer of a vehicle includes a sensor configured to measure a parameter of the trailer, a sensor interface board electrically coupled to the sensor and configured to retrieve the measured parameter, and a master controller communicatively coupled to the sensor interface board via a data bus.

CLAIMS:
1 . A smart trailer system coupled to a trailer of a vehicle, the smart trailer system comprising:
a sensor configured to measure a parameter of the trailer;
a sensor interface board electrically coupled to the sensor and configured to retrieve the measured parameter; and
a master controller communicatively coupled to the sensor interface board via a data bus.
