Claims:

1. A computer system comprising software for translating natural language into a
formal language executable on a programmable device, wherein said system
includes:

processing means;

input means (3.1.1) for presenting natural language text to said system;

a lexicon of terms (3.2.0);

a text parser operative to partition natural language text presented by the input
means (3.1.1) into sequences of sequences of pretokens;

a type assignment processor (3.2.1.3) configured to assign syntactic types to
pretokens provided by the text parser by comparison to lexical terms in the lexicon
and determining their status as tokens;

a type contextualization processor (3.2.1.4) configured to generate a sequence
of expressions by reassigning lexical types to tokens received from the type
assignment processor (3.2.1.3) based on syntactic context;

a term correlation processor (3.2.2.1) configured to correlate terms occurring in
a set of expressions provided by the type contextualization processor (3.2.1.4) in
order to replace indirect references by direct references:

characterised by:

a type reduction matrix to map sequences of tokens into a relative reduction
ordering that represents syntactic dependencies between tokens;

a term reduction processor (3.2.2.2) configured to use the type reduction matrix
to determine syntactic dependencies between tokens in an expression provided by the
term correlation processor (3.2.2.1);

a term inversion processor (3.2.2.3) configured to construct chains of syntactic
dependencies among lexical terms in an expression provided by the term reduction
processor (3.2.2.2) and to determine the dependencies between those chains;

syntactic trees representing the syntactic structures of the expressions;

a syntactic algebra comprising syntactic terms formally representing processed
expressions;

a syntactic representation processor (3.2.3) configured to construct syntactic
algebraic terms representing processed expressions on the basis of the syntactic trees;

a semantic object algebra comprising semantic objects as internal references of

terms in the syntactic algebra:
