1. An adaptive MAP channel decoding apparatus, comprising:

a channel estimator (420) adapted to calculate a channel noise power and a
scaling factor;

a MAP channel decoder (440), wherein an input signal is multiplied by the scaling
factor so that the MAP channel decoder operates regardless of a current channel

state;

a controller (430) adapted to determine an operation mode of the MAP channel
decoder (440) according to changes in the channel noise power and the scaling

factor; and

the MAP channel decoder (440) being adapted to selectively operate in a static
channel mode or in a time-varying mode, wherein the MAP channel decoder is
adapted to use in the static channel mode the following equation for decoding:
xEy = min(x, y) - log(1+e7!x-¥!)
and wherein the MAP channel decoder is adapted to use in the time-varying
mode the following equation for decoding:
xEy = min(x, y)
where x and y are metric values, and

wherein the controller (430) is adapted to determine the operation mode of the
MAP channel decoder (440), and

wherein a current channel state is checked based on the changes in the channel
noise power or the scaling factor, and wherein the time-varying channel mode is
determined when the current channel state is determined to be time-varying, and

otherwise the static channel mode is determined.
