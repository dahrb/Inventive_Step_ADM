CLAIMS

1. A broadcast receiver for converting an image format of video data comprising:
an external interface (121) for being coupled to an external device;

an image converter (126) for converting the image format according to at least one
parameter;

an encoder (127) for encoding the format changed video data;

a file system converter (128) for changing the encoded video data into a file system
supported by the external interface (121); and

a display (400) for displaying a preview window (410) providing an image of the format
changed video data,

wherein the image converter (126) adjusts an aspect ratio of the video data to an
aspect ratio employed by the external device coupled to the external interface (121).

2. The broadcast receiver of claim 1, wherein the parameters includes at least one of
format type, width, height, voice format parameter, compression format parameter and user
interface parameter.

3. The broadcast receiver of claim 2, wherein the format type includes manual and
automatic.

4. The broadcast receiver of claim 3, wherein the display (400) displays a control
panel (420) for setting the at least one parameter, when the format type is automatic, the
control panel (420) includes a part for inputting a model name and a model number.

5. The broadcast receiver of claim 1, wherein the display (400) displays the preview
window (410) and a control panel (420) for setting the at least one parameter on the main
screen displaying the data.

6. The broadcast receiver of claim 1, wherein the control panel (420) includes a

interface (121); and
