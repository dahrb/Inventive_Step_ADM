MAIN REQUEST

1. A non-transitory machine-readable storage medium that provides instructions
that, if executed by a processor, will cause the processor to generate an application
programming interface (API) (120) that allows an API-implementing component (110) to
perform operations, the operations comprising:

launching an application indexer (330) to run in a process having privileges
identical to privileges of a third party application (310) executable on the processor,
wherein the process is separate from other processes involving other third party
applications executable on the processor;

instantiating, by the application indexer (330), an instance of an application
search bundle (340) specific to the third party application (310) that executes with
privileges identical to the privileges of the third party application (310), the third party
application (310) providing the application search bundle (340) specific to the third party
application (310) to access records of application data stored in a search database;

passing, by the application indexer (330) from the instance of the application
search bundle (340), identifiers of changed records to the instance of the application
search bundle (340) by the application indexer (330), wherein the instance of the
application search bundle (340) retrieves the identified record from the search database
without launching the third party application (310); and

the application indexer (330) indexing the identified records received from the

instance of the application search bundle (340) in the search database (380).
