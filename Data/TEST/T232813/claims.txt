Clean Copy

1. A method (400) for registering a wireless terminal (504) with a home
agent (510), comprising:

receiving (404) identifying indicia associated with a subscriber from the
wireless terminal when the wireless terminal requests access to a network;

providing (406) the identifying indicia to a authentication server (508);

receiving (408), at a base station (506), a profile associated with the
subscriber (504), wherein there are a plurality of home agents to which
registration information from the wireless terminal could be routed, wherein
the plurality of home agents are associated with different mobile virtual
network operators, wherein the profile identifies one or more home agents
(510) that are assigned to a mobile virtual network operator associated with
the subscriber, and wherein the profile is received from the authentication
server (508); and

routing (410) registration information from said wireless terminal (504)
to an identified home agent, wherein routing registration information
comprises receiving a registration request at the base station and transmitting

the registration request from the base station to the identified home agent.

2. The method (400) of claim 1, further comprising creating an MIP tunnel
to the identified home agent (510).

3. The method (400) of claim 1, wherein the identified home agent (510) is
determined through identifying a network associated with the identifying

indicia provided to the authentication server (508).
4. The method (400) of claim 1, wherein the identified home agent (510) is
determined through identifying the mobile virtual network operator associated

with the identifying indicia provided to the authentication server (508).
