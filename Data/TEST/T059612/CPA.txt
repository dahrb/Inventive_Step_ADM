TITLE:
LCD panel controlled by two process elements

TYPE:
US Patent

ABSTRACT:
A multifunction peripheral which can perform copying, printing, faxing and scanning. The MFP is made up of a hard output unit, essentially a copier, and a control unit, essentially a print server. User interface definitions for copying are embedded in the hard output unit. User interface definitions for printing, faxing and scanning are stored in the control unit. When the hard output unit resets, it loads the UI definitions from the control unit. The UI definitions in the control unit are stored as a file and are easily updated from a LAN.
