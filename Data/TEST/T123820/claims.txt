NEW MAIN REQUEST

1. An apparatus comprising:

a processor [108] configured to execute instructions stored in memory [110] to:

represent [1202] a region of interest with one or more polygons;

determine [1204] a plurality of sub-polygons that are contained within the one
or more polygons, wherein each of the sub-polygons is associated with a unique code
comprising a geohash code; and

generate [1206] a first index system based on at least a subset of the plurality of
sub-polygons,

wherein the processor is further configured to:

receive a location query from a client device, wherein the location query
includes a location identifier providing geolocation of the client device;

determine a query identifier corresponding to the location identifier and
comprising a geohash code;

compare the query identifier with the index system to determine that the
location identifier provided by the client device is within the region of interest; and

provide a service associated with the region of interest to the client device over a

communication network.

2. The apparatus of claim 1, wherein the processor [108] is further configured to
determine a tree structure corresponding to the region of interest and to generate the

first index system based on the tree structure,

wherein the tree structure includes a branch node corresponding to a first set of bits in
the geohash code of a sub-polygon and a leaf node corresponding to a second set of bits
in the geohash code of a sub-polygon and the branch node is associated with a
geographic area that is larger than that of the leaf node, and wherein the processor [108]
is further configured to generate indices for the index system by traversing the tree

structure from the branch node to the leaf node.

3. The apparatus of claim 2, wherein the processor [108] is further configured to:
