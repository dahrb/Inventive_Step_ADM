TITLE:
Dynamic visual indications for input devices

TYPE:
US Patent

ABSTRACT:
An input device for providing input to a computing device. The input device includes a body, a visual element, and a processing element in communication with the visual element. The processing element dynamically changes a graphic displayed by the visual element to correspond to presentation data corresponding to the input device as presented to the computing device. The dynamic changes in the graphic provide indication to a user regarding the current state of the input device.

CLAIMS:
1. An input device for providing input to a computing device comprising:
a body;
a visual component; and
a processing element in communication with the visual component; wherein
the processing element dynamically changes a graphic displayed by the visual component to correspond to presentation data of the input device to the computing device.
2. The input device of claim 1, wherein at least one characteristic of the graphic directly corresponds to at least one characteristic of the presentation data.
3. The input device of claim 1, wherein the visual component is a display screen.
4. The input device of claim 1, wherein the visual component is positioned on a backend of the body.
5. The input device of claim 1, further comprising at least one sensor in communication with the processing element, wherein data sensed by the at least one sensor changes the presentation data.
6. The input device of claim 1, further comprising:
a nib connected to the body and configured to interact with the computing device; and
a force sensor configured to detect changes in force applied to the nib, the force sensor in communication with the processing element; wherein
when the force sensor senses an increase in a force applied to the nib, a diameter of the graphic increases; and
when the force sensor senses a decrease in the force applied to the nib, the diameter of the graphic decreases.
7. The input device of claim 6, wherein when a color of the presentation data, a color of the graphic changes.
8. A stylus for providing input to a computing device in communication with a screen, comprising:
a body configured to be gripped by a user;
a tip connected to a first end of the body; and
a display connected to the body, the display providing a graphic; wherein
the graphic corresponds to presentation data of the stylus as illustrated on the screen.
9. The stylus of claim 8, wherein the graphic directly corresponds to the presentation data of the stylus.
10. The stylus of claim 8, wherein
the graphic comprises a graphic diameter and a graphic color; and
the presentation data comprises a presentation diameter and a presentation color; wherein
and at least one of the graphic diameter or the graphic color correspond to the presentation diameter or the presentation color, respectively.
11. The stylus of claim 10, wherein the graphic diameter is the same as the presentation diameter and the graphic color is the same as the presentation color.
12. The stylus of claim 8, further comprising a sensor configured to detect a user input, wherein at least one characteristic of the graphic varies in response to the user input.
13. The stylus of claim 12, wherein the sensor is a force sensor.
14. The stylus of claim 13, wherein as a force applied to the tip increases, the graphic increases in diameter or width.
15. The stylus of claim 12, wherein the sensor is a gyroscope.
16. The stylus of claim 8, wherein the display is positioned on a back end of the body.
17. The stylus of claim 16, wherein the display is a liquid crystal display screen, a touch screen, or a light emitting diode.
18. An input system comprising:
a computer having a processor;
a touch screen in communication with the processor; and
a stylus configured to communicate with the computer via the touch screen, the stylus comprising:
a body configured to be gripped by a user;
a tip connected to a first end of the body;
an graphic display connected to the body, the graphic display providing a visual output including a graphic; wherein
the graphic corresponds to an output of the stylus on the touch screen.
19. The input system of claim 18, wherein the graphic varies based on at least one of a sensed input to the stylus or an active application running by the processor.
20. The input system of claim 18, wherein the stylus comprises at least one sensor configured to detect a user force applied to the stylus.
