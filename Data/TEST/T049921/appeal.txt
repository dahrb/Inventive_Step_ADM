The appellant appealed against the examining division's decision refusing the European patent application in suit. II. The examining division decided that - the main request did not meet the requirements of Article 54 EPC - the main request and auxiliary requests 1, 1a and 2 to 5 did not meet the requirements of Article 56 EPC. III. The examining division made reference, inter alia, to the following documents: D1    US 2014/340318 D2    US 2005/057535 D3    JP 2013 045362 D4    JP 2013 137696 D5    YI-MIN CHEE, "Ink Markup Language (InkML) W3C Recommendation", 20 September 2011 IV. With its statement setting out the grounds of appeal, the appellant maintained and resubmitted the requests underlying the decision under appeal and also submitted a further auxiliary request, i.e. auxiliary request 6. Moreover, the appellant requested that the appeal fee be reimbursed pursuant to Rule 103(1)(a) EPC. V. The board summoned the appellant to oral proceedings. In a communication under Article 15(1) RPBA, the board set out its provisional opinion on the case. VI. By letter dated 7 June 2023, the appellant submitted further auxiliary requests, i.e. auxiliary requests 1b to 1i, as well as new versions of auxiliary requests 4 and 5. VII. At the oral proceedings, the appellant withdrew auxiliary requests 1b to 1i and 2 to 6 and its request for the reimbursement of the appeal fee under Rule 103(1)(a) EPC, and submitted an amended version of the new auxiliary request 1a. VIII. Finally, the appellant requested that the decision under appeal be set aside and that a patent be granted based on the main request, or on auxiliary request 1 on which the decision under appeal was based, or on the amended version of the new auxiliary request 1a as submitted at the oral proceedings before the board. IX. Claim 1 of the main request reads as follows: "A digital ink generating apparatus (2) comprising: a stroke data generator (20) configured to generate stroke data (SD0, SD1, SD2, ... ) associated with an input sensor attribute based on pen event data generated by an input sensor (3a) when an indicator (4) is operated, wherein the input sensor attribute is writing pressure obtained by the input sensor (3a); characterized in that a mapping data generator (32) configured to generate mapping data (MD1, MD2) describing a transform rule for transforming a value of writing pressure included in the stroke data (SD0, SD1, SD2, ... ) to a value of one of line width and transparency; and a digital ink assembler (31) configured to store, in a storage apparatus (2a) and in a determined data format, digital ink data including the stroke data (SD0, SD1, SD2, ... ) and the mapping data (MD1, MD2)." X. Claim 1 of auxiliary request 1 is based on claim 1 of the main request, with the additional specification that the mapping data further includes "first range data indicative of a range of the stroke data (SD0, SD1, SD2, ... ) to which the first transform rule is applied". XI. Claim 1 of auxiliary request 1a reads as follows: "A digital ink generating apparatus (2) comprising: a stroke data generator (20) configured to generate stroke data (SD0, SD1, SD2,...) associated with an input sensor attribute based on pen event data generated by an input sensor (3a) when an indicator (4) is operated, wherein the input sensor attribute is writing pressure obtained by the input sensor (3a); characterized in that a mapping data generator (32) configured to generate mapping data (MD1, MD2) that includes a first transform rule for transforming a value of writing pressure included in the stroke data (SD0, SD1, SD2,...) to a value of transparency, and first range data indicative of a range of the stroke data (SD0, SD1, SD2, ...) to which the first transform rule is applied; wherein the first transform rule is described using a mapping element specified by an InkML format, and a digital ink assembler (31) configured to store, in a storage apparatus (2a), digital ink data in the InkML format, wherein the digital ink data includes the stroke data (SD0, SD1, SD2, ...) and the mapping data (MD1, MD2)."
