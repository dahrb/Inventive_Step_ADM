A digital ink generating apparatus (2) comprising:

a stroke data generator (20) configured to generate stroke data (SDo, SD1,
SDg, ...) associated with an input sensor attribute based on pen event data
generated by an input sensor (3a) when an indicator (4) is operated,
wherein the input sensor attribute is writing pressure obtained by the input

sensor (3a);

characterized in that

a mapping data generator (32) configured to generate mapping data (MD1,
MDz2) describing a transform rule for transforming a value of writing
pressure included in the stroke data (SDo, SD1, SD2, ...) to a value of one

of line width and transparency; and

a digital ink assembler (31) configured to store, in a storage apparatus (2a)
and in a determined data format, digital ink data including the stroke data
(SDo, SD1, SD2, ...) and the mapping data (MD1, MD2).

The digital ink generating apparatus according to claim 1, wherein, the
digital ink generating apparatus (2) and the indicator (4) are separate

units.

The digital ink generating apparatus (2) according to claim 1 or 2, wherein
the determined data format is InkML format and the transform rule is

described by use of a mapping element specified by the InkML format.

The digital ink generating apparatus (2) according to one of claims 1 to 3,
wherein the mapping data generator (32) is configured to generate first
mapping data (MD1, MD2) that includes a first transform rule for
transforming a value of the input sensor attribute included in the stroke
data (SDo, SD1, SD2, ...) to a value of one of line width and transparency,
and first range data indicative of a range of the stroke data (SDo, SD1, SD2,

...) to which the first transform rule is applied.
