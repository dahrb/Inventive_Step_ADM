New Claims 1 to 3

1. An image processing apparatus (1001, 1002) having a plurality of
different functions, comprising:

an authentication unit (S601-S603) adapted to execute a user
authentication for a user who uses the image processing apparatus;

a first registration unit (S801-S809) adapted to register a plurality of
processes as a sequential processing flow which cooperates the plurality of
different functions; and

an execution unit (S1111) adapted to execute the sequential
processing flow for image data,

characterized by further comprising:

an obtaining unit (S603, S605) adapted to obtain setting data
representing a personalized processing which is personalized for the user
authenticated by said authentication unit;

a determination unit (S1105) adapted to determine whether or not a
predetermined keyword to be replaced is included in the sequential
processing flow registered by said first registration unit; and

a replacing unit (S1107) adapted to replace, based on the obtained
setting data representing the personalized processing which is personalized
for the authenticated user, the predetermined keyword included in the
sequential processing flow with the personalized processing if said
determination unit (S1105) determines that the predetermined keyword to
be replaced is included in the sequential processing flow,

wherein said execution unit (S1111) is adapted to execute the
sequential processing flow for which the predetermined keyword is replaced
with the personalized processing by said replacing unit if said determination
