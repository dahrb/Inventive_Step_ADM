TITLE:
Use of workflows for processing data on a printing device

TYPE:
UK Patent

ABSTRACT:
The generation and usage of workflows for processing data on a printing device (120) includes receiving (302) a request to create a workflow for a printing device (120). One or more operations that may be included in the workflow are displayed (304), and user-selection of at least one of the one or more operations is received (306). The user-selected operations are added (308) to the workflow, and a user-selection of an order in which multiple ones of the user-selected operations are to be performed is received (306). When the creation of the workflow is completed, an indication of such is received and the workflow is saved (318). According to another aspect, a request to process data is received (342), the appropriate workflow identified, and the data processed (346) by performing the operations in the sequence in an order identified by the sequence.

CLAIMS:
1. A method implemented in a printing device, the method comprising: receiving (342) a request to process data; accessing (344) a stored set ( 128) of one or more sequences of operations; determining, based at least in part on the request, which sequence from the stored set (128) to use in processing the data; and processing (346) the data by performing the operations in the sequence in an order identified by the sequence.
2. A method as recited in claim 1, wherein detennining which sequence from the stored set (128) to use in processing the data (346) comprises identifying a sequence indicator included as part of the request.
3. A method as recited in claim 1, wherein: receiving (342) the request to process data comprises receiving the request as an electronic mail message; and determining which sequence from the stored set (128) to use in processing (346) the data comprises checking' based on an electronic mail address to which the electronic mail message was sent, which sequence is to be used.
