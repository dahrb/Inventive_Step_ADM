CLAIMS (Main request)

A method in a base station for dynamically triggering a mobile terminal to transmit
sounding reference signals, SRS, wherein a predefined uplink symbol of an uplink
subframe is configured to be used by the mobile terminal for SRS, the method being
characterized in the steps of:

-determining (301) whether the mobile terminal shall use the predefined uplink symbol
for data transmission or not during uplink transmission,

-signaling (302) to the mobile terminal, at least partially in an uplink grant, an instruction
whether the mobile terminal shall use the predefined uplink symbol for data transmission
or not during uplink transmission, wherein the signaled instruction further comprises
information whether the mobile terminal shall use the predefined uplink symbol for SRS
or leave the predefined uplink symbol blank if the predefined uplink symbol shall not be

used for data transmission.

The method according to claim 1, wherein the signaled instruction is valid for the

predefined uplink symbol of one subsequent uplink subframe.

The method according to claim 1, wherein the signaled instruction is valid for the

predefined uplink symbol of multiple subsequent uplink subframes.

The method according to any of claims 1-3, wherein the signaling (302) to the mobile
terminal is performed if the predefined uplink symbol should not be used for data

transmission.

The method according to any of claims 1-3, wherein the signaling (302) to the mobile
terminal is performed if the predefined uplink symbol should be used for data

transmission.

The method according to any of claims 1-5, wherein the signaling to the mobile terminal

is sent as downlink control information carried by the physical downlink control channel.
