TITLE:
Informing network users of television programming viewed by other network users

TYPE:
World International Patent Organisation

ABSTRACT:
Method for informing a first network user about the activity of other network users; the method comprises receiving the information identifying the television programming watched by at least one other network user and displaying the information to the first network user on a user interface.
