TITLE:
A web browser

TYPE:
World International Patent Organisation

ABSTRACT:
A control system includes an Internet web interface to a network of at least one programmable logic control system running an application program for controlling output devices in response to status of input devices. The Web interface runs Web pages from an Ethernet board coupled directly to the PLC back plane and includes an HTTP protocol interpreter, a PLC back plane drive, a TCP/IP stack, and an Ethernet board kernel. The web interface provides access to the PLC back plane by a user at a remote location through the Internet. The interface translates the industry standard Ethernet, TCP/IP and HTTP protocols used on the Internet into data recognizable to the PLC. Residing in the PLC is a programming package accessible to a user through this interface which will allow the user to edit programs controlling the operation of the programmable logic controller system.
