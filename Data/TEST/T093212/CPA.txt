TITLE:
Circuit for storing trace information

TYPE:
US Patent

ABSTRACT:
A system for performing non-intrusive trace is provided which receives trace information from one or more processors. The trace system may be configured by a user to operate in various modes for flexibly storing or transmitting the trace information. The trace system includes a FIFO which is memory-mapped and is capable of being accessed without affecting processor performance. In one aspect, the trace system includes a trace buffer which receives trace information at an internal clock speed of the processor. In another embodiment, a compression protocol is provided for compressing trace messages on-chip prior to transmitting the messages to an external system or storing the messages in memory.

CLAIMS:
1. An integrated circuit comprising:
at least one processor; and
a debug module operatively connected to the processor, the debug module including a first-in-first-out (FIFO) buffer wherein the debug module is configurable to store trace information produced by the processor, and wherein the FIFO includes a plurality of memory-mapped registers configured to hold the trace information to enable reading of the trace information using the processor.
2. The integrated circuit according to claim 1, wherein the FIFO operates in a mode wherein trace information is discarded when the FIFO buffer is full.
3. The integrated circuit according to claim 1, wherein the debug module provides an indication to the processor that the FIFO is approaching a full level.
4. The integrated circuit according to claim 1, wherein the debug module provides an indication to an external system that the FIFO is approaching a full level.
5. The integrated circuit according to claim 2, wherein the debug module provides the indication within a finite number of storage locations from the full level of the FIFO.
6. The integrated circuit according to claim 1, wherein the memory-mapped registers are read by a read circuit independent from the processor.
7. The integrated circuit according to claim 1, the integrated circuit further comprising a system bus and wherein trace information is transmitted over a communication link separate from the system bus.
8. The integrated circuit according to claim 1, wherein the trace information comprises at least one of:
program counter information;
process identification information;
address information;
information stored in memory; and
information related to a system bus transaction.
9. The integrated circuit according to claim 1, wherein the trace information is store in a RAM-based storage unit.
10. The integrated circuit according to claim 1, wherein the trace information is stored in both a RAM-based FIFO and the FIFO buffer.
