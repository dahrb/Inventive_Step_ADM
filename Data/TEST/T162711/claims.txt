Main Request

Claims

1. A method of operating a client device to search for articles, the method
comprising:

storing a local index of client articles comprising articles of a plurality of
different types previously accessed or referenced by a user in a local data store (140);

outputting a first search query (204) for web search over a network to a remote
web search engine (170) for querying a global index of network articles, said articles
available on the World Wide Web, said first search query (204) being an HTTP GET
request;

intercepting said first search query and generating a second search query (206)
to search said local data store (140), wherein intercepting said first search query
comprises recognising, at a network monitor, an HTTP GET request for a web search,

receiving a first result set (210) as a result of the querying of said global index;

receiving a second result set (208) as a result of the querying of said local index;
and

displaying (216) the first and second results in combination.

2. The method of claim 1, further comprising modifying said first search query to

generate the second search query.

3. The method of any preceding claim, wherein said second result set is displayed

separately by article type.

4. The method of claim 3, wherein the first and second result sets are displayed
separately.
5. The method of any preceding claim, further comprising generating said first

search query in response to a user input.

6. The method of any preceding claim, further comprising generating said first

query is an implicit query based on events within the client device.
