CLAIMS —- AMENDED MAIN REQUEST:

1. A memory buffer for processing sequential input data symbols and providing
the input data symbols to an N-window mode Soft-In Soft-Out “SISO” turbo decoder
having a window size of W data symbols, comprising:

a control logic (330);

a unidirectional shift register (310) having an input terminal and an output
terminal, wherein the unidirectional shift register is configured to sequentially shift and
store 2NW sequential input data symbols from the input terminal in a predetermined
direction, and sequentially output the shifted data symbols via the output terminal; and

N bidirectional shift registers (321, 322,..., 323),

wherein each of the bidirectional shift registers includes first and second input
terminals, first and second output terminals, and a select terminal,

wherein the bidirectional shift registers are configured by means of the control
logic to be sequentially activated at intervals of W data symbols of the 2NW sequential
input data symbols received at the input terminal of the unidirectional shift register,

wherein each of the bidirectional shift registers is configured by means of the
control logic to receive first NW data symbols among the sequential input data symbols
through its first input terminal, and shift and store the received data symbols in a
predetermined direction, and at the same time, serially output previously stored second
NW data symbols through its second output terminal,

wherein each of the bidirectional shift registers is configured by means of the
control logic to thereafter receive second NW data symbols among the sequential input
data symbols through its second input terminal, shift and store the received data
symbols in the opposite direction of the predetermined direction, and at the same time,
serially output the previously stored first NW data symbols via its first output terminal,
and

wherein the control logic of the memory buffer is configured to provide the
select terminal of each of the bidirectional shift registers with a select signal for
applying the first NW data symbols to the first input terminal or the second NW data

symbols to the second input terminal.

a window-mode Soft-In Soft-Out (SISO) decoder including a subtraction
section configured to subtract an output of the unidirectional shift register of the
memory buffer from the respective LLR values, and output the subtraction result for
