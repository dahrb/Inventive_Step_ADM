CLAIMS

1. A data processing system for implementing a lottery, including:

an input terminal operable to receive data comprising a lottery sales amount corresponding to
one or more customer lottery purchase orders from a remote communication device via a public
telecommunications network;

a data storage means for storing received; and

a server operable to communicate with said remote communications device over said public
telecommunications network

wherein said data processing system is configured to store a latest lottery prize amount value
having a least partial dependence on said received data;

said data processing system configured to update automatically said latest lottery prize
amount value responsive to and on at least partial dependence on update data received by said input
terminal; and

configured to communicate said updated latest lottery prize amount value over said public
telecommunications network to a presentation device automatically when the said latest lottery prize

amount value has been updated.

2. A data processing system according to claim 1, wherein said update of said value comprises

increasing said a latest lottery prize amount value.

3. A lottery system, comprising a data processing system according to claim 2, wherein said data
storage means comprises:

a database; and

said server comprises a lottery central server, for providing lottery information to said remote
communications device, the lottery information comprising constantly changing data, including said

updated latest lottery prize amount value, related to a progressive accumulating jackpot.

4, The lottery system according to claim 3, wherein the received data further comprises a lottery

participation number.

5. The lottery system according to any of claim 3 or claim 4, wherein the received data further

comprises a customer identification and password.
