MAIN REQUEST
CLAIMS

1. A computer-implemented method for navigating in a relational database of a
product lifecycle management system, the database storing modeled objects and
relations between said objects, the PLM system comprising a graphical user interface
suitable for displaying to a user a graphical 3D representation of a hierarchy of stored
objects, the method comprising the steps of:

- selecting a first object, a first relation and a first layout;

- finding descendants of said first object in the hierarchy, which
descendants comprise second objects related to the first object according to the first
relation;

- displaying a 3D representation of the first object to the user as a set of
a 3D representations of the second objects that are laid out in 3D space and distributed
on the first layout;

- selecting one of the displayed second objects, a second relation and a
second layout;

- finding descendants of the selected second object, which descendants
comprise third objects related to the selected second object through the second relation;

- displaying a 3D representation of the first object, comprising the second
and third objects, the selected second object is replaced by 3D representations of the
third objects being laid out in 3D space and distributed on the second layout, wherein
the second objects displayed are redistributed on the second layout in the graphical 3D
representation according to a respective relative weight of said second objects, the
relative weight of an object depends on the number of descendants of said object in

the hierarchy, which are displayed in said graphical representation.

2. The method of claim 1, wherein the graphical user interface is further
adapted to display to the user a graphical cue representative of a hierarchy of a
displayed object and the descendants of said object in the hierarchy, which are

displayed to the user in said graphical representation.

3. The method of claim | or 2, wherein the objects displayed further have a

rendering size depending on their respective relative weight.

4. The method of one of claims | to 3, wherein the relative weight of an object
further depends on the size of descendants of said object in the hierarchy, which are

displayed in said graphical representation.
