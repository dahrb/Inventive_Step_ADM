Main Request

1. A method of operating a communication network device for coordinating
communication between devices in a network, comprising:

generating, by the communication network device, a first identification
code;

assigning, by the communication network device, the first identification
code to a first application executing on a first device, wherein the first identification
code is unique to the first application executing on the first device;

receiving, by the communication network device, a transmission of data
from a sending device, wherein the transmission specifies a recipient of the data using
the first identification code, the recipient being different from the sending device;

determining, by the communication network device, that the transmission
of data is incompatible with the first application based on compatibility information of
the first application;

modifying, by the communication network device, the data to generate a
version of the data that is compatible with the first application;

determining, by the communication network device, that the transmission
is incompatible with the first device based on compatibility information of the first
device;

modifying, by the communication network device, the data to generate a
version of the data compatible with the first device; and

transmitting, by the communication network device, the transmission of

data to the recipient.

2. The method of claim 1, further comprising:

receiving registration information for a second application executing on
the first device; and

generating a second identification code for the second application,
wherein the second identification code is unique, among all identification codes stored
in the communication network device, to the second application executing on the first

device.
