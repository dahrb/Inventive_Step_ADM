TITLE:
Secure identification over communication network

TYPE:
European Patent

ABSTRACT:
The invention relates to a method for providing identification data of an individual to a service over a communication network (102). The method comprises providing a device (108) to the individual, the device (108) being connectable to the mobile communication network (102) and registered in the communication network (102). The identification data are stored in the device (108). For identifying the user, the identification data are transmitted from the device (108) to the service via the communication network (102) using the registration of the device (108) in the communication network (102).

CLAIMS:
A method for providing identification data of an individual to a service over a communication network (102), the method comprising the steps of:
- providing a device (108) to the individual, the device (108) being connectable to the mobile communication network (102) and registered in the communication network (102),
- storing identification data included in an identification means (114) of the individual in the device (108);
- transmitting the identification data from the device (108) to the service via the communication network (102) using the registration of the device (108) in the communication network (102).
The method according to claim 1, wherein a code, particularly an MSISDN, is allocated to the device (108) in the communication network (102) and wherein the identification data is transmitted to the service upon a request of the service, said request being addressed to the device (108) using the code.
The method according to claim 1 or 2, wherein the identification data are transferred from the electronic identification means (114) to the device (108) using contactless communication between the electronic identification means (114) and the device (108).
The method according to one of the preceding claims, wherein the device (108) comprises an identification application, the identification application controlling the transmission of the identification data to the service via the communication network (102).
The method according to claim 4, wherein a registration system (117) initialises the identification application in response to a verification of the identification data stored in the device (108).
The method according to claim 4 or 5, wherein the identification application is pre-installed in the device (108) and is initialised in response to a verification of an initialisation code provided by the registration system (117).
The method according to one of the preceding claims, the transmission of the identification data is allowed upon successful verification of an authorisation feature input into the device (108).
The method according to one of the preceding claims, wherein the device (108) is a SIM card connected to a mobile communication device (101) and the communication network (102) comprises a mobile communication network (102).
A system for providing identification data of an individual to a service over a communication network (102), the system comprising a device (108) of the individual, the device (108) being connectable to the communication network (102) and registered in the communication network (102) and the device (108) comprising a memory unit storing a copy of identification data included in an identification means (114) of the individual; and a means for sending the identification data to the service via the communication network (102) using the registration of the device (108) in the communication network (102).
The system according to claim 9, further comprising a server (113) providing the service, the server being adapted to request the device (108) to provide the identification data, the request being addressed to the device (108) using a code, particularly an MSISDN, allocated to the device (108) in the communication network (102),
The system according to claim 9 or 10, wherein the device (108) further comprises an identification application adapted to send the identification data to the service, the identification application being initialised by a registration system (117) in response to a verification of the identification data stored in the device (108).
The system according to one of the claims 9 to 11, further comprising an electronic identification means (114) of the individual including an interface for transmitting identification data stored therein to the device (108).
The system according to one of the claims 9 to 12, wherein the device (108) is a SIM card connected to a mobile communication device (101) and the communication network (102) comprises a mobile communication network (102).
