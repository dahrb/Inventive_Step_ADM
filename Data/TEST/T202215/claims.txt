Amended Claims 1 and 2 (Clean Copy)

A moving image coding apparatus which divides a moving image into
macroblocks and codes each of the macroblocks, said apparatus
comprising: .

a macroblock size determination means (1) for determining a
size of each of the macroblocks on a sequence-by-sequence basis,
wherein the sequence is a set of a plurality of continuous frames;

a macroblock dividing means (2) for dividing an inputted image
into macroblocks each having the size determined by said macroblock
size determination means (1);

a macroblock coding means (3) for determining a coding mode
for each of said macroblocks, and for coding pixel values in each of said
macroblocks in the determined coding mode; and

a macroblock size information multiplexing means (4) for
multiplexing the macroblock size information determined by the

macroblock size determination means (1) into a bit stream.

The moving image coding apparatus according to claim 1,
characterized in that the macroblocks are further divided from a slice

divided from the moving image.
