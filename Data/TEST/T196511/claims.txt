MAIN REQUEST

A method of providing an extended table of alternatives for use in execution of a

relational database query, the method comprising:

obtaining a table (300) of alternatives, the table (300) of alternatives comprising several
groups, one group having a root entry representing the database query and additional
entries representing alternative possibilities for executing the database query and the
other groups having root entries representing sub-expressions of the database query and
additional entries representing alternative possibilities for executing the respective sub-

expression of the database query;

selecting candidate views for the query from a number of materialized views; and
for each root entry:

extracting an operator tree for the root entry;

extracting, for each candidate view, an operator tree from a view definition of the

candidate view;
matching the operator trees for the root entry and the candidate views; and

if a match is found, extending the table (300) of alternatives with the corresponding
candidate view by extending the group of the root entry with the corresponding candidate

view.

The method of claim 1 wherein extracting an operator tree (400) for an entry containing

binary joins comprises collapsing operators into a query graph.

The method of claim 2 wherein the collapsing of the operators into a query graph
comprises listing underlying tables along with predicates that are applied on them.

The method of claim 1 wherein extracting an operator tree (400) for a view comprises

collapsing operators into a primitive graph-tree.
