Title: Signalling system

Abstract: 
A battery signalling system is provided which can be used to monitor and/or control a battery (1) having a number of series connected battery cells (C.sub.i) . When used to monitor the battery cells, the battery signalling system can comprise a central battery monitoring system (3) for monitoring the industrial battery (1) as a whole, a number of cell monitoring devices (CM.sub.i) for monitoring one or more battery cells (C.sub.i) and a communication link (9) for connecting the cell monitoring devices (CM.sub.i) in series in a daisy chain configuration to the central battery monitoring system (3). In operation, the central battery monitoring system (3) can poll each of the cell monitoring devices (.sub.Cmi) in turn and analyze the data received from a polled cell monitoring device (CM.sub.i) to detect malfunctions and/or underperforming cells.
