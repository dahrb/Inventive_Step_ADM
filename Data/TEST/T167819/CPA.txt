TITLE:
Display device

TYPE:
Japanese patent

ABSTRACT:
PROBLEM TO BE SOLVED: To provide a display device suitable for mobile use and capable of flexible use according to TPO.
A display device having flexibility that can be bent is used to detect a folding position of the display device and control display contents. In particular, the size or display position of the display image is changed. Alternatively, the line feed position or line spacing of the display text is changed.

CLAIMS:
A flexible display device that can be bent;
Detecting means for detecting a bending position of the display device;
And a control means for controlling the display content of the display device based on the output of the detection means.   The display device according to claim 1, wherein a reinforcing member is attached to the display device to add strength to the flexibility of the display device.   The display device according to claim 1, wherein a size of the display image is changed based on an output of the detection unit.   The display device according to claim 1, wherein a display position of a display image is changed based on an output of the detection unit.   5. The display device according to claim 1, wherein the aspect ratio of the display image is not changed.   The display device according to claim 1, wherein a line feed position of the display text is changed based on an output of the detection unit.   The display device according to claim 1, wherein the line spacing of the display text is changed based on the output of the detection means.   The display device according to any one of claims 1 to 7, further comprising: a posture detection unit that detects a posture of the display device; and a control unit that controls display contents of the display device based on an output of the posture detection unit. .
