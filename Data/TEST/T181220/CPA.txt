Title: Method and device for migrating virtual machine parameters and virtual machine server

Abstract: Embodiments of the present invention provide a method and device for migrating virtual machine parameters and a virtual machine server. The method comprises: receiving a virtual machine parameter migration message in a non-running stage of a virtual machine, the virtual machine parameter migration message being used to enable an upstream network device of the virtual machine to migrate virtual machine parameters of the virtual machine in the non-running stage of the virtual machine, and the virtual machine parameter migration message comprising the identifier of the virtual machine. Dynamic information in corresponding virtual machine parameters in the upstream network device of the virtual machine does not change in the non-running stage of the virtual machine. Therefore, the upstream network device of the virtual machine migrates the virtual machine parameters of the virtual machine in the non-running stage of the virtual machine, which enables correct migration of the virtual machine parameters and solves the service interruption problem in virtual machine migration.
