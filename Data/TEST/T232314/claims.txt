CLAIMS

A multi mode mobile device (10) configured to switch between a
communication mode and a computing mode, the device (10) comprising:
a communication processor (18) configured to facilitate wireless voice and
data communication, when the device (10) is in the communication mode;
an application processor core (36) of an application processor (34)

configured to execute at least one computing application, when the device

- (10) is in the computing mode, wherein both the communication processor

(18) and the application processor (34) are powered by a battery (14)
characterized by

a user-manipulable input device (16) to select the operational mode of the

‘device (10) responsive to a user’s activity, the user-manipulable input

device (16) configured to switch between the computing mode and the
communication mode based on the selection; and

a Processor Local Bus, PLB, bridge processor (62) whose functions are
implemented by a dedicated portion of the communication processor (18),
wherein the PLB bridge processor (62) is configured to enable the
communication processor (18) to function as a master processor for
controlling peripheral devices and the application processor core (36) is
powered off to extend battery (14) life, when the communication mode is
selected, and

wherein the PLB bridge processor (62) is configured to enable the
communication processor (18) to function as a peripheral processor, when

the computing mode is selected.

The device (10) of claim 1, wherein the application processor core (36)

functions as a master processor, when the computing mode is selected.

The device (10) of claim 2, wherein the application processor core (36) is

associated with a processor local bus, PLB, (46).

The device (10) of claim 3, wherein the communication processor (18) is

associated with a memory bus (24) communicating with one or more
