MAIN REQUEST

CLAIMS:

1. A method performed by an electronic device with one or more processors and memory
storing one or more programs for execution by the one or more processors, the method
comprising:

providing an interface for one or more touch events, the interface configured to convey a touch
list, wherein the touch list includes touch event data to identify one or more touches on a web
page, said one or more touches being associated with a target of a touch event, and the touch
event data includes a touch identifier and at least one set of touch location coordinates for a
respective touch of the one or more touches; and

conveying the touch list to the web page for processing.

2. The method of claim |, wherein the web page includes one or more instructions for

processing the one or more touch events.

3. The method of any of claims 1-2, wherein the web page includes one or more instructions
for processing the one or more touch events in accordance with the one or more touches in the

touch list.

4. The method of claim |, further comprising generating a gesture event by combining two

or more touch events.

5. An electronic device, comprising:

one or more processors; and

memory storing one or more programs for execution by the one or more processors, the one or
more programs including instructions for:

providing an interface for one or more touch events, the interface configured to convey a touch
list, wherein the touch list includes touch event data to identify one or more touches on a web
page, said one or more touches being associated with a target of a touch event, and the touch
event data includes a touch identifier and at least one set of touch location coordinates for a
respective touch of the one or more touches; and

conveying the touch list to the web page for processing.
