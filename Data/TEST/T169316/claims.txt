Main Request EP Application 04810576.1; Attorney File P 61908

A method for providing color coordination comprising:
receiving a starting color for which coordinating colors are sought;
associating the starting color with a first color in a color database, the first color being
the closest matching color in the color database to the starting color;
retrieving one or more color palettes associated with the first color, each palette
including one or more coordinating colors, the coordinating colors being
predetermined based on the first color and a color coordination algorithm; and
fine-tuning a characteristic of the first color by
accessing a first color data structure associated with the first color, the first color
data structure being stored on a computer readable medium and including a
unique identifier for the first color data structure, a first plurality of color
metrics defining the first color, and a plurality of references to other data
structures representing neighboring colors in color space, each neighboring
color having at least one color characteristic which differs from those of the
first color;
accessing a second color data structure specified by one of the references from the
plurality of references to other data structures, and
determining a second color, said second color being specified by a second
plurality of color metrics defining the second color in the second color data

structure.

The method of claim 1 wherein the first color data structure further comprises:

a source identifier indicating a source where the first color is located; and
