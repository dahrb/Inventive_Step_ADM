MAIN REQUEST - APPEAL

CLAIMS:

l. A method for controlling a screen brightness of a portable
terminal, the method comprising:

detecting an input for displaying a screen at a first brightness value (step
201) and displaying the screen at the first brightness value (step 203);

detecting a touch on a screen for displaying an area on the screen
corresponding to the touch at a second brightness value; and

displaying the area on the screen corresponding to the touch at the second
brightness value while maintaining the screen except the area at the first
brightness value (step 207),

wherein the second brightness value is set to a value that is higher than

the first brightness value.

2. The method of claim 1, before detecting the touch, further
comprising

determining whether an input for inactivating a predetermined function
corresponding to a touch is input,

when the inactivating input is inputted, inactivating the predetermined

function corresponding to a touch (step 205).

3. The method of claim 2, wherein detecting the touch comprises;

detecting a touch on a screen while the inactivating input is maintained.

4. The method of claim 2, wherein the determining whether the
input for inactivating the predetermined function corresponding to the touch is
input comprises:

determining whether a key for inactivating the predetermined function

corresponding to the touch is input (step 205).
