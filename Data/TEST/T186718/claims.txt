Main request

1. A computer-implemented method for managing an archive for determining
approximate matches associated with strings occurring in data records of a dataset accessible by

a graph-based computation, the method including:

pre-processing, by a pre-execution module (110), data records (304) to determine a set of
string representations that correspond to strings occurring in the data records,

including:

generating (308), for each of at least some of the string representations in the set,
a plurality of close representations that are each generated from at least

some of the same characters in the string;

calculating a frequency of occurrence in the data records for each of the at least

some of the strings represented in the set of string representations; and

renormalizing the frequency of at least one string by adding the counts of the

strings that are potential approximate matches of the at least one string;

storing entries (310) in an archive (114) that each represent a potential approximate
match between at least two strings based on their respective close representations;

and

executing, by an execution module (112), one or more data processing applications with
one or more entries retrieved from the archive and representing one or more

respective results of the pre-processing.

2. The method of claim 1, wherein each string representation comprises a string.

3. The method of claim 2, wherein each close representation consists of at least some of

the same characters in the string.

4. The method of claim 3, wherein generating the plurality of close strings for a given
string in the set includes generating close strings that each have a different character deleted

6. The method of claim 5, wherein generating the plurality of close strings for a given

character deleted from the given string includes generating close strings that each have a single

given string if the given string is longer than the predetermined length.

8. The method of claim 1, further including generating, for each of at least some of the
string representations in the set, a significance value that represents a significance of the

corresponding string based on a sum that includes the renormalized frequency.

9. The method of claim 8, wherein the significance value is generated based on an

inverse of the sum.

10. The method of claim 8, further including determining whether different phrases that
include multiple strings correspond to an approximate match by determining whether strings
within the phrases correspond to an approximate match, wherein the strings within the phrases

are selected based on their corresponding significance values.
