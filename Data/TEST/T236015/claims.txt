Claims
(Main Request)

1. In a medical ultrasound system, a method for creating a comprehensive report
simulation, the method comprising:

storing patient data and raw data corresponding to ultrasound signals in a first
database contained in the medical ultrasound system (300-320);

causing the system to enter in a report simulation mode (330) so that the medical
ultrasound system is forced to behave as if an actual exam was taking place by taking
simulated data as input for the report instead of input from ultrasound input devices and
users;

providing the simulated data by processing the raw data to obtain data
corresponding to ultrasound images and the patient data (340); and

creating a simulated report (350) based on the simulated data provided as input.

2. The method of claim 1 wherein storing patient data in the first database comprises
storing all possible values of patient information.

3. The method of claim 1 wherein storing raw data comprises storing raw data that

corresponds to the ultrasound signals associated with every type of ultrasound exam.

4. The method of claim 1 wherein using the patient data and processed raw data to
create a report simulation comprises using a user selected subset of all possible
combinations of patient data (345) and processed raw data from the database to simulate a

report.

5. The method of claim 1 wherein the medical ultrasound system remains responsive
to user interaction during using the patient data and the ultrasound images to create a

report simulation.

6. A medical ultrasound system comprising: a display (16); a processor (50) coupled
to the display; a user interface (28) coupled to the processor; and an analysis package
stored on a computer readable medium (58) and operatively connected to the processor,
the analysis package providing a user the ability to create a comprehensive report

simulation according to claim 1.
