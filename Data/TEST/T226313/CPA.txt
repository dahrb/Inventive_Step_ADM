Title: Information processing apparatus allowing multiple logins

Abstract: An information processing apparatus accepts operating instruction only from a user who has logged into the information processing apparatus, and is assigned with a screen of the information processing apparatus. The information processing apparatus includes a login processing unit configured to allow a first user to login and be assigned with the screen and to allow a second user, after the first user, to login and be assigned with the screen by reassigning the screen from the first user to the second user while maintaining a login status of the first user.

Type: US Patent

Claims: 

1. An information processing apparatus which accepts operating instruction only from a user who has logged into the information processing apparatus and is assigned with a screen of the information processing apparatus, comprising:
a login processing unit configured to allow a first user to login and be assigned with the screen and to allow a second user, after the first user, to login and be assigned with the screen by reassigning the screen from the first user to the second user while maintaining a login status of the first user.
