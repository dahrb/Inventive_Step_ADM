MAIN REQUEST

CLAIMS:

1. A method performed by an electronic device with one or more processors and memory
storing one or more programs for execution by the one or more processors, the method
comprising:

providing, to a web page for processing by the web page, a touch list including touch data
identifying all touches on the web page, wherein the touch data includes a touch identifier and at
least one set of touch location coordinates for a respective touch of the said all touches on the
web page; and

generating a display of the web page.

2. The method of claim 1, further comprising generating a gesture event by combining two

or more touch events.

3, The method of claim 2, wherein the gesture event includes one of: scale information and
rotation information, the scale information includes a scaling value, and the rotation information

includes a rotation value.

4, An electronic device, comprising:

one or more processors; and

memory storing one or more programs for execution by the one or more processors, the one or
more programs including instructions for:

providing, to a web page for processing by the web page, a touch list including touch data
identifying all touches on the web page, wherein the touch data includes a touch identifier and at
least one set of touch location coordinates for a respective touch of said all touches on the web
page; and

generating a display of the web page.

5. The electronic device of claim 4, wherein the one or more programs include instructions

for generating a gesture event by combining two or more touch events.
