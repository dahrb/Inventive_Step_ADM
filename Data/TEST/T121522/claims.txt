CLAIMS

[Claim 1]

An automatic analyzer comprising:

an input section to which sample containers containing
samples are inputted;

a storage means for storing analysis items or the number
of analysis items requested for respective samples;

a sample processing section having a nozzle sucking part
of the samples to be discharged to other containers in
accordance with the analysis items or the number of analysis
items stored in the storage means; and

a conveyance means for conveying the sample containers
to a suction position by the nozzle,

wherein the conveyance means, when new samples are
inputted to the input section, controls conveyance of the new
samples based on the number of analysis items in which the
suction by the nozzle has not been completed (the number of
remaining analysis items) inanalysis items requested for other
samples scheduled to be dispensed before the new samples.
[Claim 2]

The automatic analyzer according to claim 1,

wherein the conveyance means conveys the new samples so
as to be sucked next to the other samples when the numberof

remaining analysis items is smaller than a given number.

[Claim 3]

An automatic analyzer comprising:

an input section to which sample containers containing
samples are inputted;

a storage means for storing analysis items or the number
of analysis items requested for respective samples;

a sample processing section having a nozzle sucking part
of the samples to be discharged to other containers in
accordance with the analysis items or the number of analysis
items stored in the storage means; and

a conveyance means for conveying the sample containers
to a suction position by the nozzle,

wherein the conveyance means, when new samples are
inputted to the input section, controls conveyance of the new
samples based on a period of time necessary for suction of
analysis items in which suction by the nozzle has not been
completed (remaining dispensing time) in analysis items

the new samples.

[Claim 4]

The automatic analyzer according to claim 3,

wherein the conveyance means conveys the new samples so
as to be sucked next to the other samples when the remaining
dispensing time is shorter than a given period of time.
