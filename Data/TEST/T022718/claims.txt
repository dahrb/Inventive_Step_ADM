A system for supporting a plurality of instances of the same application on a

wireless smart device, the system comprising:

a wireless smart device for communicating with a wireless reader, the wireless

smart device including:

a plurality of instances of a same application for performing wireless
transactions with an external device, the application having a first
application identifier, each instance having a respective second
application identifier that is unique to the instance and different from the
first application identifier, wherein at least some of the instances are of
the same type; and

an application manager for identifying one of the instances associated
with the second application identifier as active, for detecting a request
identifying the application by the first application identifier from a
wireless reader for performing a wireless transaction with an application
identified by the second application identifier, and for communicating
the request to the identified active instance associated with the second
application identifier using the second application identifier for the
identified active instance.

The system of claim 1 wherein the wireless smart device comprises one of a

mobile telephone, a key fob, a physical card, a personal digital assistant, and

a device provisioned with a soft card.

The system of claim 1 wherein the wireless smart device is adapted to

communicate using a close-proximity wireless technology.
