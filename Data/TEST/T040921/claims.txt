CLAIMS

1. A storage device (112) comprising:

a non-volatile memory (118; 120) configured to store data from a host (106),
wherein the host (106) is operable in at least an active mode or a low power periodic
update mode, the active mode comprising a longer initialization phase than the low
power periodic update mode; and

a controller (114) configured to:

detect when the host (106) is in the low power periodic update mode at least in
part by:

receiving an identify drive command from the host (106);

determining that an amount of time between when the storage device (112) is
powered up and when the identify drive command is received from the host (106) is
less than a predetermined amount of time, the predetermined amount of time being
reflective of the difference between the shorter initialization phase of the host when it
is in the low power periodic update mode and the longer initialization phase of the
host when it is in the active mode;

place the storage device (112) in a power up in standby mode when the host
(106) is in the low power periodic update mode; and

when the storage device (112) is in the power up in standby mode, the
controller (114) is further configured to:

receive write data from the host (106) to be written to a target location;

cache the write data from the host (106) in a volatile memory (116); and

write the write data from the host (106) to the target location when a cache flush

command is received from the host (106).

2. The storage device (112) of claim 1, wherein the non-volatile memory
(118; 120) further comprises a rotating magnetic media, and when the storage device
(112) is in the power up in standby mode, the controller (114) is further configured to:

prevent the rotating magnetic media from spinning up, until the cache flush
command is received from the host (106) or data stored in the rotating magnetic

media is requested by the host (106) for a read command.
