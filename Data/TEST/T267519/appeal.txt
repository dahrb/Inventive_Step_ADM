The appeal is against the decision by the examining division, dispatched with reasons on 2 May 2019, to refuse European patent application 14737430.0, on the basis that the main request did not meet the requirements of Articles 84 and 56 EPC, and the auxiliary request did not meet the requirements of Article 123(2) EPC. The following document cited during the first instance proceedi D1:  US 2012/102159 A1. The following document has been introduced by the board: D3:  Wikipedia article "Diskless node", version of 2013-03-23 08:47, retrieved by the board on 9 August 2023, URL: https://en.wikipedia.org/w/index.php?title=Diskless_node II. A notice of appeal was received on 25 June 2019, the appeal fee being paid on the same day. A statement of grounds of appeal was received on 2 September 2019. III. The appellant requested that the decision under appeal be set aside and a patent granted on the basis of claims 1 to 10 of the main or claims 1 to 9 of the auxiliary request that were the object of the refusal (filed on 19 December 2017 and 4 April 2019, respectively). The appellant made a conditional request for oral proceedings. The further text on file is: description pages 3 to 13 as filed with entry into the regional phase before the EPO, 1 and 2 received on 29 May 2017; drawing sheets 1 to 5 as filed with entry into the regional phase before the EPO. IV. The board issued a summons to oral proceedings. In an annex to the summons, the board introduced the above-mentioned document D3 and set out its preliminary opinion on the appeal, according to which the decision of the first instance should be maintained. V. On 27 October 2023, the appellant filed a response to the summons, maintaining its requests, apart from an indication that page 1, lines 4 to 9 and par. [0033] to [0034] of the description should be deleted. The appellant further provided arguments in response to the board's preliminary opinion. VI. On 17 November 2023, the appellant informed the board that it would not attend the oral proceedings, which were subsequently cancelled. VII. Claim 1 of the main request reads as follows: "A method of bootstrapping from a remote image file comprising: loading, by a processor, an initial bootloader; employing the initial bootloader to download (503) a final bootloader from the remote image file via a network; employing the final bootloader to download (509) a kernel and root file system mounting data needed to allow the kernel to mount the image file as an Internet Small Computer System Interface, iSCSI, device from the remote image file without downloading an entire initial root file system; and executing (513) the kernel to bootstrap the processor based on the root file system mounting data and completing booting from the image file by downloading only the portions of the image file needed to complete the bootstrapping process." VIII. Claim 1 of the auxiliary request distinguishes itself from that of the main request in that the term "initial root file system" is replaced by "initrd file for a Linux system". IX. Claim 6 of the main request and claim 5 of the auxiliary request relate to devices having device features corresponding to the method features of claim 1 of the respective request.
