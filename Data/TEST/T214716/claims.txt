e-mail messages as spam or legitimate on a client mail server (200), the method
comprising:

electronic messages (180) directed to different users who have email addresses registered
on the client mail server (200); .

classifying (515) the received electronic messages (180) as legitimate or spam
messages;

identifying (535) unknown messages that could not be classified as legitimate or
spam;

obtaining (550) metadata (860) of the unknown messages, the metadata (860)
including at least a set of hash sums (830) for an unknown message and an IP address of a
sender of the unknown message;

plurality of clusters forming a cluster index tree based on a degree of similarity between a

2. The method of claim 1, wherein classifying unknown messages as legitimate or
spam based on cluster ratings further includes: |
classifying (565) a message (180) as spam when a cluster rating is above a first
threshold; and
classifying (560) a message (180) as legitimate when a cluster rating is below a

second threshold.

3. The method of claim 1, wherein:
the greater is the number of messages (180) in a cluster having similar hash sums
(830) and different IP addresses of message senders, the rating of a cluster indicates that
the cluster contains metadata (860) of spam messages; and
the greater is the number of messages (180) in a cluster with similar hash sums
(830) and the same IP address of the message sender, the rating of said cluster indicates

that the cluster contains metadata (860) of legitimate messages.

4, The method of claim 1, wherein receiving the electronic messages (180) includes:
receiving (710) the electronic messages (180) from one or more message traps
(170); and
when a message (180) is received from a message trap (170), modifying the
rating of a cluster to which said message was assigned to indicate that the cluster contains

metadata of spam messages.

5. The method of claim 1, wherein placing (553) the metadata (860) of the
unknown messages into a plurality of clusters includes:
placing (553) the metadata (860) of the unknown messages into a plurality of
clusters using the cluster index tree, in which each node of the cluster index tree identifies

hash sums (830) common to a plurality of legitimate messages or spam messages.

6. The method of claim 1, wherein obtaining (550) the metadata (860) of the
unknown messages further includes:

separating each unknown message into a plurality of fragments (820);
