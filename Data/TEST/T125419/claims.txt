Claims

1. A method (300) performed by a user terminal for obtaining local Internet
Protocol, IP, access capability information, comprising:
receiving (302) from an access point an indication over broadcast
common signaling that comprises capability of the access point to
provide local IP access connectivity to a mobile device and,
wherein the indication is received via an overhead channel that
comprises system information blocks, wherein the local IP access
connectivity enables access to at least one locally available node
by the mobile device, and wherein the indication is received
before the mobile device has connected to the access point; and
requesting (304) the local IP access connectivity only when the
indication specifies that the access point has the capability to

provide the local IP access connectivity.

2. The method (300) of claim 1, wherein the indication comprises a field

within system information blocks of the overhead channel.

3. A wireless communications apparatus (600) configured to obtain local
Internet Protocol, IP, access capability information, comprising:
means (604) for receiving an indication over broadcast common

signaling that comprises capability of an access point to provide
local IP access connectivity for the wireless communications
apparatus, wherein the indication is received via an overhead
channel that comprises system information blocks and, wherein
the local IP access connectivity enables access to at least one

locally available node, and wherein the indication is received
