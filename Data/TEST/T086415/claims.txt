CLAIMS — Main Request

1. A method of recording a program, comprising:

storing (220), in response to a user request, at least one content file (510) that
includes first and second program segments;

creating and storing (230) at least one index file (530) that includes program
specific information (540) associated with the first and second program segments,
wherein the program specific information includes a program’s service number that is
used to access a program map table stored in the index file, wherein the program map
table includes packet identifiers, the index file further including an identification of a
splice point denoting a transition between the first and second program segments; and

creating and storing (240) a splice index (560) that includes timing information

specifying a time at which the splice point occurs.

2. The method of claim | further comprising receiving (210) the first and second
program segments over a broadband network in the first and second program transport

streams, respectively.

3. The method of claim | wherein the content file (510), index file (530) and the
splice index (560) are stored in a network digital video recorder, DVR, associated with a

broadband network headend.

4. The method of claim | wherein the timing information includes a timing offset to
denote a point in time at which the splice point occurred relative to a start time of the first

program segment.

5. The method of claim 4 wherein creating and storing (240) the splice index further

comprises:
