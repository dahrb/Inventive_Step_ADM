MAIN REQUEST

A method for interleaving input data having a size of L, comprising the steps of:
sequentially storing the input data in a memory;
determining whether the input data size L is a multiple of 2", wherein m > 1;

if the input data size is not a multiple of 2", determining a size N of a virtual address area
by adding (811) an offset value, OSV, to the input data size L, wherein the size N of the

virtual address area is Nox 2, wherein N, is an area number and L + OSV = Ngx2”;

defining a plurality of address generation areas (N;,N2,N3...Ng) having a size of 2™ in the
virtual address area of size N;

generating N virtual random addresses including L virtual addresses indicating the input
data of size L and OSV virtual addresses not indicating the input data;

identifying, for each of the L virtual random addresses, a number of the OSV virtual

addresses each of whose value is smaller than the each of the L virtual random addresses;

generating random addresses by subtracting, for the each of the L virtual random
addresses, the number of the OSV virtual addresses whose value is smaller than the each
of the L virtual random addresses from the each of the L virtual random addresses; and

reading the stored input data from the memory using the generated random addresses.

The method as claimed in claim 1, wherein the random address is a pseudo noise, PN,

sequence.

The method as claimed in claim 1, wherein the offset value is a certain value to be added to
a binary value obtained by converting the input data size into the binary value, such that the
number of consecutive zero bits from the least significant bit of the binary value becomes at

least more than one.
