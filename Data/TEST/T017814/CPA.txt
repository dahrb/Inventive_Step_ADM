TITLE:
Copying machine management system

TYPE:
Japanese patent

ABSTRACT:
PROBLEM TO BE SOLVED: To smoothly execute the reception work of a copying machine connected to a communication line by means of a server with comparatively small performance by permitting the respective copying machine to periodically access to the management file of the self client directory of the server. SOLUTION: The server is provided with a client list file storing the belonging parts of the copying machines, client directories generated for the respective belonging parts and a picture file directory storing picture data and the like transmitted from the respective copying machines. At the time of reception, the control parts 24 of the respective copying machine accesses to the self client directory of the server, checks the total number of received documents of the reception header management file and recognizes whether received data exists or not. When it exists, a document header file name is obtained, the picture file directory is accessed, the picture file which fits to a document header file name is obtained, it is temporarily stored in a memory part 25 and compiling work is executed based on processing information. Then, data is outputted to a printing part 23.

CLAIMS:
1. A copier management system comprising a plurality of digital copiers connected to a communication line and one server, wherein the server stores image data transmitted from each digital copier. An image file directory having an image file; and a client directory having a reception header management file which is created for each digital copying machine and stores management data relating to image data to be received. An image scanner unit that scans a document to be transmitted, an input unit that specifies a transmission partner, a memory unit that stores received image data, a printing unit that prints the received image data, and a control unit, The control unit communicates with the server at the time of transmission and transmits the image data scanned by the image scanner unit to the image of the server. In addition to writing to the image file in the file directory, the management data relating to the image data is written to the reception header management file in the client directory of the transmission destination specified by the input unit. Check whether there is image data to be received by accessing the reception header management file, and if there is image data to be received, access the image file directory and copy the corresponding image data stored in the image file. A copier management system storing the image data in the memory unit and instructing the printing unit to print the image data stored in the memory unit. 2. The image file directory includes a document header file storing a total number of distributions of a transmission destination specified by an input unit of the digital copying machine, and the control unit controls the printing of the corresponding image data. When the copy is printed out, the total number of received documents in the received header management file is subtracted by “1” and the corresponding management information is deleted, the total number of distributions of the document header file is subtracted by “1”, and the total number of distributions is zero (0). 2. The copier management system according to claim 1, wherein the image data of the corresponding image file is erased when the condition is satisfied.
