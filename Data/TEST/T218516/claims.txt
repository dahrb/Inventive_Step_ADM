MAIN REQUEST
CLAIMS

1. An apparatus for displaying multimedia contents, the apparatus
comprising:

an alignment condition determination unit (420) which is configured to determine an
alignment condition corresponding to a received first user command signal among a plurality of
alignment conditions;

a display unit (470) comprising a screen having a plurality of regions, wherein the display
unit is configured to display the determined alignment condition in a first region of the screen;

characterized in that the apparatus further comprises:

a detailed condition determination unit (430) which is configured to determine a detailed
condition, among a plurality of detailed conditions, of the alignment condition determined by the
alignment condition determination unit (420), wherein the detailed condition is determined
corresponding to a received second user command signal;

a contents extraction unit (450) which is configured to extract first multimedia contents
according to the detailed condition determined by the detailed condition determination unit (430);
and in that

the display unit (470) is configured to display the determined detailed condition in a
second region, and a second multimedia contents (331) among the extracted first multimedia
contents in a third region of the screen (330),

wherein the first user command signal and the second user command signal are direction
and/or numeral button signals from numeral and/or directional buttons of an input unit (410) and
wherein the buttons which cause the first user command signal are different from buttons which

cause the second user command signal.

2. The apparatus of claim 1, wherein the alignment condition determination
unit (420) determines the alignment condition according to an up/down button signal among the

direction button signals.

3. The apparatus of claim 1, wherein the detailed condition determination unit
(430) determines the detailed condition according to a left/right button signal among the direction

button signals or one of the numeral button signals.
