MAIN REQUEST

1. A portable videophone unit (20) comprising:

an image display section (21) configured to display images; and

an image data transmitting-receiving section (15) configured to perform two-way
communications by transmitting image data and sound data to an opposite party’s unit
and by receiving image data and sound data from the opposite party’s unit,

the portable videophone unit being characterized by further comprising:

a control section (1) configured to automatically activate an automatic response
mode of the portable videophone unit when an incoming call is received from the
opposite party’s unit, if calling data of the incoming call contains a personal identification
number, and the opposite party’s unit is successfully authenticated by the personal
identification number, the automatic response mode comprising setting the portable
videophone unit to an off-hook status and enabling a two-way communication between

the portable videophone unit and the opposite party’s unit.

2. The portable videophone unit (20) according to claim 1, further comprising:

an information storage section (2) configured to previously store a personal
identification number to be used for identifying the opposite party’s unit as a particular
party; and

a judging section configured to judge whether or not an incoming call is from
the particular party by comparing the personal identification number included in the
calling data of the incoming call with the personal identification number previously
stored in the information storage section (2),

wherein the control section (1) is configured to permit the data
transmitting-receiving section (15) to perform the two-way communication only when

the judging section judges that the incoming call is from the particular party.

3. The portable videophone unit according to claim 1, wherein
the control section is configured to judge whether or not the automatic response
mode is already activated when the incoming call from the opposite party’s unit is

detected.

4. The portable videophone unit according to claim 1, further comprising:

a selecting section (3, 4, 5) configured to select a communication mode from at

5. The portable videophone unit according to claim 4, wherein

the control section is configured to, if the calling data does not contain the
personal identification number, or the opposite party’s unit is not successfully
authenticated by the personal identification number, activate a normal response mode in
which the two-way communication is not enabled unless a predetermined key (23a) of
the portable videophone unit is pressed, and

the normal response mode and the automatic response mode are switchable.

6. A method for a portable videophone unit by which a communication mode is
selectable from at least a mode in which a two-way communication is carried out by
transmitting sound data and image data to an opposite party’s unit and by receiving sound
data and image data from the opposite party’s unit, and a mode in which the two-way
communication is carried out by transmitting sound data only to the opposite party’s unit
and by receiving sound data only from the opposite party’s unit, the method being
characterized by comprising a step of:

making a phone call by transmitting to the opposite party’s unit, data containing
a telephone number of the opposite party’s unit, identification data which indicate that
the communication mode is the mode in which the two-way communication is carried
out by sound data and image data, and a personal identification number for identifying
the portable videophone unit and enabling the opposite party, if an automatic response
mode is activated, to authenticate the portable videophone unit by the personal
identification number and to set the opposite party’s unit to an off-hook status for

enabling the two-way communication.
