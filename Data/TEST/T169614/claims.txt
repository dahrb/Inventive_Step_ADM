Claims — Main Request

1. A display method of a portable electronic device, comprising:

activating a character input function;

detecting an orientation of the electronic device;

selecting a first mode or a second mode according to the orientation of the electronic
device; and

displaying, on a single display, a virtual key pad comprising a plurality of virtual keys
in an input region, and an output region being configured to display characters input via the
virtual key pad, according to the selected mode;

wherein the display of the characters and the virtual key pad according to the first
mode is different from the display of the characters and the virtual key pad according to the
second mode, and

wherein one of the differences between the display of the characters and the virtual
key pad in the first mode and the display of the characters and the virtual key pad in the
second mode is a font size of the characters input via the virtual key pad and displayed in the
output region;

wherein the first mode comprises a portrait mode and the second mode comprises a

landscape mode.

2. The method of claim 1,

wherein one of the differences between the display of the characters and the virtual
key pad in the first mode and the display of the characters and the virtual key pad in the
second mode is at least one of (i) a position of at least one of the plurality of keys of the
virtual key pad, (ii) an arrangement of at least one of the plurality of virtual keys of the
virtual key pad, and (iii) a type of the virtual key pad.

3. The method of claim 1,
wherein the setting of the first mode or the second mode according to the orientation
of the electronic device comprises:
setting the first mode when the orientation of the electronic device
corresponds to a portrait orientation, and
setting the second mode when the orientation of the electronic device

corresponds to a landscape orientation, and

wherein a virtual key of the virtual key pad in the first mode is a larger size than a size

of the virtual key of the virtual key pad in the second mode.

4. The method of claim 1, wherein the displaying of the input region and the
output region comprises:

increasing a number of virtual keys of the virtual key pad or enlarging the size of the
virtual key pad in response to switching from the first mode to the second mode; and

decreasing the number of virtual keys of the virtual key pad or reducing the size of the

virtual key pad in response to switching from the second mode to the first mode.

5. The method of claim 1, wherein the font size of the characters in the first

mode is larger than the font size of the characters in the second mode.

6. The method of claim 1, further comprising:

displaying the characters smaller than previously-displayed characters in response to
switching from the first mode to the second mode; and

displaying the characters larger than previously-displayed characters in response to

switching from the second mode to the first mode.

7. The method of claim 1, further comprising:
adjusting a position of line breaks of the characters displayed in the output region in

response to switching between the first mode and the second mode.

8. The method of claim 1, further comprising:
determining a size for at least one of a virtual key configuring the virtual key pad and
the characters displayed on the single display screen in response to the setting of at the first

mode or the second mode.

9. The method of claim 1, further comprising:

measuring, via a sensor, a value corresponding to the motion of the electronic device;
and

comparing the measured value with a threshold value,

wherein the setting of the first mode or the second mode is based on the comparison.
