The appeal is against the decision of the examining division refusing European patent application No. 13 741 036 (published as WO 2013/112987 A1) on the ground that none of the requests then on file involved an inventive step within the meaning of Article 56 EPC. II. During the oral proceedings before the board, the appellant (applicant) requested that the decision under appeal be set aside and that a patent be granted on the basis of the main request or the first auxiliary request, both filed with the appellant's letter dated 26 May 2022. III. Reference is made to the following document, cited also in the decision under appeal: D2: US 2011/0275346 A1 IV. Claim 1 of the main request has the following wording: A web-to-mobile, communication messaging system comprising: a) at least one web server (160) computing device providing Internet access (190) to a website (120) that is comprising a web-based user interface (180) configured to accept a plurality of (126) targeting records created by a plurality of website users, wherein each targeting record (138) from the plurality of targeting records comprises: 1) message data uniquely associated with one advertising message (156) from a plurality of advertising messages published on the website (110), and 2) a target mobile subscriber identifier (152); b) a database (128) configured to perform: b1) storing (124), identifying, and retrieving (146) of said plurality (126a) of targeting records; and b2) on receiving (136), from an application software element (154), a query (134) requesting message data from at least one stored targeting record (138b) satisfying the received query, identify at least one stored targeting record (138b) satisfying the received query, and send (146) at least the message data (156a) included in the at least one identified stored targeting record to the application software element (154); and c) the application software element (154), wherein the application software element is configured to perform at least the following steps: c1) intercept (132) a data communication transmission, wherein the intercepted data communication transmission (130) is originated by a source mobile communication device (102) and is addressed to a destination mobile communication device (152); c2) obtain (132) the communication identifier (122) identifying the destination mobile communication device (152) to which the intercepted data communication transmission (130) is addressed to; c3) send (136) to the database (128a) a query (134) requesting message data from at least one stored targeting record (138b) satisfying the sent query (134), wherein the sent query 1) comprises a first identifier (122) identifying the destination mobile communication device (152), and 2) requires that the target mobile subscriber identifier in the at least one stored targeting record (138b) satisfying the sent query matches the first identifier (122) provided in the sent query; and, c4) on receiving (142), from the database (128a), the message data (156a) included in the at least one identified stored targeting record (138b) satisfying the sent query (134), add the message data received (156a) from the database to the content of the intercepted data communication transmission, and send the intercepted data communication transmission to the destination mobile communication device (152); wherein the system is characterized in that: d) said each targeting record (138) further comprises a source communication identifier identifying a mobile communication device uniquely associated with the website user creating said each targeting record (106); e) the application software element (154) is further configured to obtain (132) the communication identifier (122) identifying the source mobile communication device (102); and, f) the sent query 1) comprises a second identifier (122) identifying the source mobile communication device (102), and 2) further requires that the source communication identifier in the at least one stored targeting record satisfying the sent query matches the second identifier provided in the sent query. V. Claim 1 of the first auxiliary request includes the same features as claim 1 of the main request formulated in a different order. VI. The appellant argued essentially that the features distinguishing claim 1 of the main request from D2 were achieving the technical effect of conveying to a mobile subscriber receiving a text message with an attached advertising message the identity of the sender (of the advertising message) while minimizing the number of bits added to the data transmission. These features were technical and not obvious to the skilled person starting from D2. The subject-matter of claim 1 of the main request involved thus an inventive step. The same arguments were also presented for the first auxiliary request.
