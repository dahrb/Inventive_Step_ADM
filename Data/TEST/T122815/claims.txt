CLAIMS — main request:

1. A method of determining an ambient parameter set associated with a textual
description, the method comprising the steps of:

searching a database (19) by using the textual description, the database (19)
comprising a plurality of files, characterized in that each file comprises information related to
a file content, for obtaining a subset of files whose information matches the textual
description, and

analyzing the subset of files for obtaining the ambient parameter set related to
the textual description,

in which the ambient parameter set comprises one or more from the group of
light value, color value, intensity value, hue value, saturation value, sound indicator,
background sound, background noise, , or a sensor parameter provided by lighting devices,

air-conditioning equipment, audio/video devices, or devices for spreading smells or odors.

2. A method according to claim 1, in which the ambient parameter set comprises

spatial parameters.

3. A method according to claim | or 2, in which analyzing the subset of files
comprises determining average parameter values for the ambient parameter set from the

subset of files.

4. A method according to any one of the preceding claims, further comprising

setting an ambient device (15), using the ambient parameter set.

5. A method according to any one of the preceding claims, further comprising
selecting the file from the subset of files which best matches the obtained ambient parameter

set.

6. A method according to any one of the preceding claims, in which the plurality

of files comprises pictures, and in which analyzing each file comprises dividing each file into
