TITLE:
Social network for location sensing

TYPE:
US Patent

ABSTRACT:
Systems and methods for social networking. Location-related data and other behavioral and exogenously generated characteristics are used to replace or supplement self-generated profiles in order to enhance the quality and trustworthiness of the matches made using the system and facilitate the inputting of profile information.

CLAIMS:
1-36. (canceled)
37. A method comprising:
receiving, at a server, information identifying a plurality of devices detected at a location, each device associated with a user;
accessing, via the server, a user profile associated with each user associated with a detected device, each user profile comprising user information specific to each user;
extracting, via the server, user information from each user profile associated with a user of a detected device; and
creating, via the server, an entity profile for the location based on the extracted user information of each user associated with a detected device.
38. The method of claim 37, wherein the entity profile is a dynamic profile that adjusts to the user information extracted from the user profiles associated with the users of the detected devices.
39. The method of claim 37, further comprising:
communicating entity profile information comprised within the entity profile to each detected device.

43. The method of claim 41, wherein the entity profile information further comprises user profile information related to users associated with detected devices currently at the location.
