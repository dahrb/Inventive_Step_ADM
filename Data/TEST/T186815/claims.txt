New MAIN REQUEST

1. A computer program product tangibly embodied in an information carrier, the
computer program product including instructions that, when executed, generate on a display
device a backup graphical user interface (300) comprising:

a view display area that presents a current view of a window,

an input control that , when selected, causes restoration of the window in accordance
with a user-selected portion of an earlier version of the window,

the view display area further presents a plurality of snapshots (304a-d; 702, 704, 802,
804; 900) that animatedly move in the view display area in response to user selection of one
or more navigation tools (307a-b; 308a-b; 902a-b), wherein each snapshot as presented in the
view display area (304a-d; 702, 704; 802, 804; 900) includes a visual representation of a
corresponding earlier version of the window, the earlier version of the window including one
or more elements that are selectable by a user for restoration; and

wherein a first snapshot of the plurality of snapshots includes a first element

that a user can select, and wherein selection of the input control, after selection of the first
element in the first snapshot, causes restoration of the window with only the first element of

the first snapshot being restored.

2. The computer program product of claim 1, where the view display area further
includes a user-activated information area that presents information about a selected

snapshot.

3. The computer program product of claim 2, where the information area provides data

associated with the selected snapshot including when the selected snapshot was created.

4. The computer program product of claim 2, where the information area provides data

associated with the selected snapshot including a location of the data of the selected snapshot.

5. The computer program product of claim 1, where the current view of the window is
included in a timeline, the timeline including several visual representations of earlier versions

of the window.

6. The computer program product of claim 5, where the several visual representations of
earlier versions of the current view of the window are presented as a stack of snapshots (700)
and, upon user selection of the one or more user navigation tools (307a-b; 902a-b), a previous

or next snapshot (702, 704) is brought to the top of the stack of snapshots (700).

7. The computer program product of claim 6, where the navigation tools include one or
more scroll bars for scrolling through visual representations of the earlier versions of the
window, including scrolling to additional visual representations of earlier versions of the

window not initially shown in the view display area.

8. The computer program product of claim 6, where the navigation tools include one or
more arrow buttons for scrolling to additional visual representations of the earlier versions of

the window not initially shown in the view display area.

9. The computer program product of claim 5, where the earlier versions of the window
in the timeline are presented with a corresponding date range associated with the earlier

versions of the window.

10. The computer program product of claim 9, where the date range is a single date.

11. The computer program product of claim 5, wherein the backup graphical user
interface further includes another input control for modifying the timeline to include only
visual representations of earlier versions of the window that differ from the current view of

the window.
