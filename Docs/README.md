# Docs/ — ADM specification

Reference documents for the inventive-step ADM (the formal model the code implements).

| File | Contents |
|------|----------|
| `Inventive_Step_ADM_Document.pdf` | The ADM structure: main ADM, Sub-ADM 1 (reliable technical character), Sub-ADM 2 (objective technical problem), nodes and acceptance conditions. |
| `Inventive_Step_Inference_Rules_Document.pdf` | The inference rules / factor logic underlying the nodes and the factor questions. |

These specs are the authority for `ADM/inventive_step_ADM.py`, `ADM/questions.json`, and the
node names that appear throughout the analysis (e.g. `OTPNotObvious`, `CandidateOTP`).
